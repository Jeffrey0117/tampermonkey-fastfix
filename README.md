# fastFix

在自己的網站上，**按住 Alt 點一段字** → 打新的字 → Enter。原始碼裡的那段字就被換掉了。
改完幾處，按一次「送出」：一個 commit 加一次 push。

不用開編輯器，不用叫 AI。改字本來就只是「找到、換掉」。

```
按住 Alt 點標題
  立即免費開始
  ┌──────────────────────┐
  │ 先用再說               │
  │ Enter 改 · Esc 取消    │
  └──────────────────────┘
畫面上的字當場變 · 左下角：已改 3 處，還沒送出 [送出]
```

- 只想改其中幾個字：先選取那幾個字，再 Alt + 點。
- 不用設定哪個網站是哪個專案。服務拿那段字去你的專案資料夾找，找得到就改，找不到就是改不了
  （所以在別人的網站上按了也不會怎樣）。改成功一次後它會記住這個網域是哪個專案。
- 每個網站第一次改會慢一點（要把所有專案找過一遍，幾秒到十幾秒），之後很快。
- 好幾處都有同一段字 → 列出檔名、行號讓你點一個。
- **送出** = 一個 commit（`chore: 網頁改字 N 處`）加 `git push`。你的站怎麼部署就照原本的方式部署。

## 兩個零件

| | 是什麼 |
|---|---|
| `fastfix.user.js` | 油猴腳本：接 Alt + 點、畫輸入框、把「舊字 → 新字」送出去 |
| `server.js` | 本機服務：只聽 `127.0.0.1:4480`，在你的 repo 裡找字、換掉、commit、push。Node，零依賴 |

## 安裝

需要 Node 20 以上、git，瀏覽器裝好 Tampermonkey。

```bash
npm run init        # 產生 .env（隨機金鑰），已經有就不動
npm run autostart   # 放一個開機自動啟動的捷徑，並且現在就啟動
```

然後瀏覽器開 `http://127.0.0.1:4480/setup`：

1. 按「安裝腳本」，Tampermonkey 跳出來按安裝。
2. 回到設定頁按 `F5`，看到「已連上」就完成。金鑰是腳本自己從設定頁拿的，不用複製貼上。

不要自動啟動：`powershell -File scripts/autostart.ps1 -Remove`。只想手動跑：`npm start`。

## 改不了、不會動的

改不了（會把一句給 AI 的指令放進剪貼簿，貼給它就能改）：

- 字是程式拼出來的，或來自資料庫、設定檔。
- 一次選取跨了好幾個元素（中間夾著標籤）。

不會動：

- 有你還沒 commit 的修改的檔。
- 壓縮過的檔（`.min.*`）、超過 1MB 的檔、git 沒追蹤的檔。
- 新的字裡多了原本沒有的 `< > { }`、引號、反斜線或換行（可能弄壞程式）。

還沒有「放棄修改」：改錯就再改一次，或在那個專案裡 `git checkout -- 檔名`。

## 服務

| | | |
|---|---|---|
| `GET /health` | 不用金鑰 | 活著嗎 |
| `POST /fix` | 要金鑰，JSON | `{ text, to, url, pick? }` → 在原始碼裡把字換掉 |
| `POST /submit` | 要金鑰，JSON | `{ url }` → commit 加 push |
| `GET /pending?host=` | 要金鑰 | 還沒送出幾處 |
| `GET /setup` | 只給本機直接開 | 設定頁 |
| `GET /fastfix.user.js` | 不用金鑰 | 腳本本體（裡面沒有金鑰） |

金鑰用 `Authorization: Bearer <FASTFIX_TOKEN>`。POST 只收 `application/json`：網頁可以偷偷跨站送
`text/plain`，但送 JSON 加金鑰標頭會被瀏覽器擋下來，所以別的網頁沒辦法叫它改你的檔。

設定（`.env` 或環境變數）：

| | 預設 | |
|---|---|---|
| `FASTFIX_TOKEN` | 必填 | 沒有就不啟動 |
| `PORT` | 4480 | |
| `HOST` | 127.0.0.1 | |
| `FASTFIX_ROOTS` | 這個 repo 的上一層資料夾 | 你的專案放哪。裡面每個 git repo 都會被找；多個資料夾用 `;` 分開 |
| `FASTFIX_HOME` | `~/.fastfix` | 狀態檔（網域對應哪個專案、還沒送出的修改） |

## 測試

```bash
npm test
```

涵蓋單一命中、原始碼跨行、多處挑選、找不到、危險符號、不碰髒檔、送出、push 失敗可重試、金鑰。
腳本本體是用無頭瀏覽器實跑驗的（Alt + 點 → 改 → 畫面變 → 送出 → 遠端有 commit），還沒放進 `npm test`。
